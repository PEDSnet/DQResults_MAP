Usage

Reference the schema from an XML instance

Replace the namespace URI to match your XSD targetNamespace. 


<?xml version="1.0" encoding="UTF-8"?>
<local:dqresult
  xmlns:local="https://pedsnet.github.io/DQResults_MAP/"
  xmlns:dc="http://purl.org/dc/elements/1.1/"
  xmlns:dcterms="http://purl.org/dc/terms/"
  xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
  xsi:schemaLocation="https://pedsnet.github.io/DQResults_MAP/
                      https://pedsnet.github.io/DQResults_MAP/schema/DQRDP.xsd">

If you encounter a 404 error, confirm the file paths under docs/schema/... match exactly (case-sensitive).
