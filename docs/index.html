How to reference the schema from an XML instance

Example (replace the namespace URI to match your XSD targetNamespace):

<dqresult
  xmlns="YOUR_TARGET_NAMESPACE_HERE"
  xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
  xsi:schemaLocation="https://pedsnet.github.io/DQResults_MAP/docs/schema/dqresult-map.xsd">
</dqresult>
